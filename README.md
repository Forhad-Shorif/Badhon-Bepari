# বাধন বেপারী পোর্টফোলিও

খামার শ্রমিক ও দিনমজুর **বাধন বেপারী**-এর ব্যক্তিগত পোর্টফোলিও। সাইটটি
Next.js দিয়ে তৈরি, সম্পূর্ণ বাংলায় লেখা এবং মোবাইল, ট্যাব ও ডেস্কটপে
রেসপন্সিভ।

## শুরু করার নিয়ম

প্রথমে ডেভেলপমেন্ট সার্ভার চালু করুন:

```bash
npm run dev
# অথবা
yarn dev
# অথবা
pnpm dev
# অথবা
bun dev
```

তারপর ব্রাউজারে [http://localhost:3000](http://localhost:3000) খুলুন।

`src/app/page.tsx` সম্পাদনা করে পেজের গঠন বদলানো যায়। ফাইল সংরক্ষণ
করলেই পেজ নিজে নিজে আপডেট হবে।

সাইটের সব লেখা `src/lib/content.ts` ফাইলে আছে। সিভি তৈরির উৎস ফাইল
`resume.html` এবং ডাউনলোডযোগ্য ফাইল `public/বাধন বেপারী.pdf`।
